# 通用规则审计义务样例

供规则扫描和验证契约回归共同使用。`operations.go` 使用任意导入别名，包含风险操作、有界读取、显式超时、资源释放、原子创建及并发所有权反例。`unrelated.go` 用于验证无关代码与环境变量读取不会触发这些规则。

这些文件仅作为静态分析输入，不执行其中的网络、文件和并发操作。安全控制反例仍应生成操作候选；规则命中不等于漏洞确认，必须保留给 verifier 检查有效控制。

`controls.go` 单独提供字节预算、条目数量、资源释放、有效超时、原子创建和任务所有权控制，用于验证这些操作信号不会被扫描阶段静默省略。源码凭据与调试配置规则在该文件不应命中。

`filesystem_paths.go` 覆盖导入别名、解压条目路径的字符串拼接、动态打开标志及有效本地路径约束。规则按最终文件操作产生候选，有效约束仍由 verifier 判断；fixture 不执行文件操作。
