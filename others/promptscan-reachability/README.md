# PromptScan 命令注入可达性样例

三个目录是彼此隔离的 Go 小项目，用于对比 PromptScan 对漏洞可达性和安全负例的判断：

- `reachable`：HTTP 路由已注册，查询参数进入 `sh -c`；期望识别命令注入并引用真实路由。
- `unreachable`：同样的危险函数存在，但没有注册到 HTTP 路由；不应声称该函数能通过 HTTP 入口访问。
- `safe`：HTTP 参数仅作为固定 `echo` 可执行文件的独立参数传入，没有 shell 解释；期望不报告命令注入。

每个项目单独扫描，避免其他样例为模型提供上下文。结果需检查候选状态、数据流证据、处理器注册证据和复现入口；仅有 `detected` 候选不代表漏洞已确认。
