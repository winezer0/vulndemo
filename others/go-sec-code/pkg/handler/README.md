# testdata/go-sec-code/pkg/handler

## 包定位

安全审计测试样例或集成测试夹具，仅用于提供可重复的输入、漏洞模式和预期行为。

## 主要职责

- 以本包公开类型和函数作为稳定边界，避免上层依赖内部实现。
- 在本包内完成输入校验、错误传播和状态约束。
- 跨包协作使用领域 DTO 或调用方接口，保持依赖方向单向。

## 关键文件与测试

生产文件：`user.go`、`ping.go`。

测试文件：无。

测试应覆盖正常场景、边界值、错误分支和公开 API；测试数据应硬编码在 `*_test.go` 中。

## 依赖边界

- 不依赖 `_references/` 下的参考内容。
- 外部框架、数据库、文件系统和 Provider 依赖应停留在适配边界。
- 禁止通过全局状态或反向引用组合根形成隐式耦合。

## 当前状态与建议

测试或样例目录，仅供测试和审计验证使用。
